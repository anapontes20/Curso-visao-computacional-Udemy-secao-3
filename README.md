# Curso-visao-computacional-Udemy-secao-3
Este projeto foi desenvolvido como parte dos meus estudos em Visão Computacional através de um curso da Udemy. O objetivo é explorar diferentes técnicas e bibliotecas utilizadas para detecção e reconhecimento de faces em imagens e vídeos.

Durante o desenvolvimento, foram aplicados conceitos e ferramentas como:

OpenCV para captura e processamento de imagens e vídeos; Haar Cascades para detecção facial baseada em classificadores em cascata; Dlib para detecção de faces e localização de pontos faciais (facial landmarks); Redes Neurais Convolucionais (CNNs) para compreender abordagens modernas de detecção e reconhecimento facial.

O projeto realiza a detecção de rostos em tempo real utilizando a webcam, permitindo visualizar na prática como diferentes algoritmos identificam faces em imagens.

Além de servir como exercício de aprendizado, este repositório documenta minha evolução nos estudos de Visão Computacional, processamento de imagens e aplicações de Inteligência Artificial.
